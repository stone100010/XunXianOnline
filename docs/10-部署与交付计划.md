# 10 · 部署与交付计划

> 决策：Vercel + 托管 PostgreSQL（Neon 或 Supabase）· 大爆炸式一次性对外交付（文档保留内部开发顺序控制风险）

---

## 1. 部署架构

```
GitHub repo（pnpm monorepo）
  → Vercel（Next.js app：玩家端 + admin + API；Turborepo 构建）
  → Neon/Supabase PostgreSQL（业务库；Supabase 时可复用其 auth 备用账号体系）
  → LLM 供应商 API（智谱 GLM 默认，OpenAI 兼容可切换，key 存 DB 配置）
```

### 环境变量

| 变量 | 说明 |
|---|---|
| DATABASE_URL | PG 连接串（pooler） |
| DIRECT_DATABASE_URL | 迁移直连 |
| DEVICE_COOKIE_SECRET / ADMIN_SESSION_SECRET | 签名密钥 |
| LLM_API_KEYS_* | 各供应商 key 兜底（正式配置在 admin_settings，加密存储） |
| CRON_SECRET | 定时任务鉴权 |

### Vercel 要点

- Hobby 10s/Pro 60s 函数超时：回合管线常规路径 P95 < 8s；S 级回合拆"引擎结算（同步）+ 叙事 SSE（流式）"两段（02 号文档 §3.1）。
- Drizzle 迁移：CI 执行 `drizzle-kit migrate`（或 Vercel Build 阶段）。
- 静态内容种子：部署后管理后台一键"导入 content 包基线"。
- Cron（Vercel Cron）：每日数据聚合物化视图刷新 + LLM 成本日报汇总 + 道果码恢复限流清理。

### 数据安全

- 每日 PG 自动备份（Neon PITR）；llm_calls/analytics 按月归档策略。
- 密钥加密（AES-GCM，密钥走 Vercel env）。

## 2. 内部开发顺序（大爆炸交付下的风险控制）

虽然对外一次性交付，内部按依赖顺序推进，每个阶段保持可运行可演示：

| 阶段 | 内容 | 依赖 |
|---|---|---|
| P1 地基 | Monorepo 脚手架、shared schema、DB 迁移、content 包基线、CI/测试基建 | — |
| P2 引擎 | engine 全模块（combat/growth/world/compass/events/breakthrough）+ 单测 ≥90% + 回放工具 | P1 |
| P3 核心循环 | 建角 API+UI、回合管线、存档/道果码、基础叙事（模板降级版即可玩） | P2 |
| P4 LLM 层 | 供应商抽象、prompt 体系、主叙事/意图/简报场景、降级链路 | P3 |
| P5 内容 | 10 主线剧本 60 阶段全量 + 事件链/秘境模板 + 坊市货架数据生产 | P2（可与 P4 并行） |
| P6 子系统 | 背包/坊市/百艺/道缘/NPC 池/势力/传承轮回/终章 | P3 |
| P7 后台 | refs CRUD + 仪表盘 + 埋点 + prompt/LLM 管理 | P1-P6 |
| P8 打磨 | 演出动效全量、移动端适配走查、性能预算达标、平衡仿真调参 | 全部 |
| P9 交付 | 内测（固定种子全主线通关自动化跑测 + 人工体验）→ 公开上线 | 全部 |

P5 内容生产与 P4 并行是压缩总工期的关键路径；剧本 Schema（06 号文档）必须最先冻结。

## 3. 验收清单（上线门槛）

**功能**
- [ ] 10 条主线均可从建角玩到终章+封号（自动化 + 人工各至少 1 次）
- [ ] 回合管线：常规回合 P95 < 8s；降级链路演练通过（人为断 LLM 可继续游玩）
- [ ] 道果码：跨设备恢复、防误输校验、限流生效
- [ ] 防 SL：无任何可回滚路径（API 审计确认）；双击推进幂等
- [ ] 传承/轮回/完全重开三路径数据正确
- [ ] 7 域地图、坊市三级、背包、百艺、道缘可用

**质量**
- [ ] engine 单测 ≥ 90%，骰子分布卡方通过；600 回合自走不变量无违例
- [ ] 回放一致性：抽样 20 存档×随机 50 回合重放 delta 一致
- [ ] LLM 主叙事 zod 通过率 ≥ 98%（内测统计），降级率 < 2%
- [ ] 移动端：iOS Safari / Android Chrome 真机走查（安全区/键盘/弱网重试）
- [ ] 首屏 JS ≤ 200KB gzip

**运营准备**
- [ ] 后台仪表盘核心指标可用（漏斗/经济/成本/降级率）
- [ ] prompt 版本管理 + LLM 切换演练
- [ ] 每日备份与恢复演练
- [ ] 二期项冻结清单：Web Push、账号体系、PWA、付费点、立绘
