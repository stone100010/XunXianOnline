# 08 · 前端与移动端规范

> Tailwind CSS + shadcn/ui + Framer Motion · 手机竖屏优先（375-430px 基准）· 桌面居中最大 480px 容器（保留宽屏双栏信息模式）· TanStack Query + Zustand

---

## 1. 页面结构

```
/                    存档选择（3 槽卡片 + 道果码恢复入口）
/create              角色创建向导（7 步）
/game                主游戏壳（底部 Tab：本月 | 地图 | 道缘 | 背包 | 我的）
  本月 Tab           开局状态卡流 + 天机简报 + 决策罗盘 + 未竟仙途 + 自由输入
  /game/turn/:no     月末结算页（演出区 + 结算面板）
/game/map            三层灵图（钻入式）
/game/destiny        天命主线详情 / 终章回顾
/game/history        历史回看
/admin               管理后台（独立布局，见 09 号文档）
```

游戏状态获取：`GET /turn` 为查询缓存核心（queryKey: ['turn', archiveId]）；action/next 成功后 invalidate。

## 2. 设计语言

- **主题**：暗色仙侠水墨——底色玄青（#0d1117 系），主色暗金（#c8a24b），点缀朱砂/青碧；毛玻璃卡片 + 细金边分隔（对应设定 ⚜️ 分隔线）。
- **字体**：衬线中文标题（霞鹜文楷/思源宋体 webfont）+ 无衬线正文。
- **图标**：emoji 作视觉锚点（沿用设定十九章规范）+ lucide 图标库功能位。
- **禁令**：禁止 ASCII 拼框/表格边框（设定规范），分隔一律用 CSS 边框与 Unicode 装饰符。
- 预留立绘接入：NPC 卡与终章页有 `portraitUrl` 可选字段，MVP 为空时显示 emoji+姓氏印章占位。

## 4. 演出规范（分级）

| 级别 | 触发 | 表现 |
|---|---|---|
| S | 渡劫、天命决战、终章、轮回 | 全屏遮罩场景动画（粒子/水墨晕染）+ 分镜播放 + 专属 BGM 位 |
| A | 战斗、突破、秘境核心、重大机缘 | FateDiceWheel + 震屏 + DeltaFloat 连播 |
| B | 日常回合 | Typewriter + 轻过渡（150ms） |

- 演出由 `sceneBeats`（05 号文档 §4）驱动编排；所有动画可点击跳过（尊重快节奏玩家）。
- 动效统一 Framer Motion；`prefers-reduced-motion` 全局降级。

## 5. 移动端细节

- 竖屏单列布局；底部 Tab + 安全区适配（`env(safe-area-inset)`）；关键操作在拇指区（罗盘与"进入下月"按钮固定底部）。
- 触控目标 ≥ 44px；罗盘选项整行可点。
- 长叙事分页感：Typewriter 完成后折叠为可展开全文。
- 弱网：所有 mutation 有 loading 态与失败重试（幂等保证）；SSE 断线自动重连续流（按 turnRecordId 续传）。
- 刷新/误退恢复：进入 /game 时以服务端 `turnNo` 为准拉取当前状态，无本地推进逻辑（服务端权威）。

## 6. 性能预算

- 首屏 JS ≤ 200KB gzip（游戏页组件按 Tab 懒加载；地图/终章动态 import）。
- 列表虚拟化：背包/历史（可能数千行）。
- Webfont 子集化（仅常用 3500 字 + 项目字词）。

## 7. 状态管理约定

- TanStack Query：所有服务端数据（回合/背包/NPC/地图），默认 staleTime 30s。
- Zustand（persist 仅 UI 偏好）：主题、动效开关、Tab 记忆、打字速度。
- 不在客户端持有任何"游戏真相"副本的写路径。
