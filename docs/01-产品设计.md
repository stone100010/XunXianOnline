# 01 · 产品设计：设定 → 系统完整映射

> 来源：《玄幻修仙模拟器提示词.md》V8.1.3。每节标注设定章节出处，并给出手游化后的产品设计与 UI 呈现方案。
> 原则是**忠实还原机制**，同时把原"文本排版界面"升级为富 UI 组件 + 叙事流。

---

## 1. 产品骨架

### 1.1 核心循环（设定·第四章）

```
每月开局页（状态总览+天机简报+决策罗盘+未竟仙途）
   → 玩家选择 1 个罗盘选项 / 自由描述行动
   → 叙事展开（打字机流式呈现，关键节点演出）
   → 月末结算面板（纪要/战斗/数值/收支/物品/道缘/仙途）
   → 点击「进入下月」→ 世界演化（NPC行动/势力消长/事件推进）→ 回到开局页
```

- 每月单决：一回合一次主要行动决策，日常修炼自动结算不消耗决策。
- 年度节律：1-3 月天命之召 / 4-5 月自由 / 6-7 月因缘际会 / 8-12 月自由。
- 关联奖励：连续专注同一命途触发【道心坚定】隐性加成。
- 选项保鲜：未选中的常规选项 1-4 个月保鲜期，过期自然发展或消失。

**UI**：开局页为纵向滚动的 Tab 结构卡片流；决策罗盘为按六类分组的选项卡列表，每项显示类型标签（天命/因缘/⚠️风险）、保鲜期倒计时角标；底部常驻"自由描述"输入框。

### 1.2 三层引导（设定·第五章）

| 层级 | 实现 | UI |
|------|------|-----|
| Lv.1 天道叩门 | 条件满足时规则引擎注入罗盘选项 | 罗盘中高亮金色边框选项 |
| Lv.2 进度提示 | 月末结算中的任务线进度行 | 结算面板"未竟仙途"区 |
| Lv.3 后果预警 | 不可逆决定前的独立确认 | 全屏确认弹窗（仙侠风警示） |

连续 3 回合未选【天命】【因缘】标签 → 暂停 Lv.1 引导，仅保留 Lv.3。

## 2. 角色创建（设定·第二章）

分步向导（移动端单步一屏，含每项含义说明 —— 新手引导决策）：

1. **姓名/性别**：输入 + 选择。道号游戏中后期获得。
2. **种族**：人族（悟性+5%）/ 妖族（根骨+10%，可化形）/ 灵族（气运+5%，寿元绵长）。
3. **年龄**：16-25 / 26-45 / 46-60 / 61-99 四段，各有事件与判定差异。
4. **灵根**：随机生成 + 开局包保底。五系×品级（凡/中/上/极/异/废），直接展示修炼速度修正。
5. **出生地**：7 大修真域（中州/东荒/南明/西极/北冥/岭南/海外），展示初始加成与特色。
6. **开局包**：10 选 1（天生道体/坊市学徒/没落血脉/遗孤散修/转世大能/佛道童子/炼丹世家/宗门杂役/铸剑山庄/大器晚成），每包含初始资产、修为、社交、**专属天命主线**。
7. **先天道韵**：10 选 1（明察秋毫/未卜先知/七窍玲珑/道音灌耳/过目不忘/五行亲和/磐石之志/天人感应/雷厉风行/奇货可居）。

创建完成后：系统按地域+开局包生成 10-15 位初始可结识 NPC（来自 NPC 池匹配，见 §8）。

**UI**：每步卡片化选择，选中项展示数值影响预览；最后一步生成"命盘预览"（属性总览+天命主线简介）确认开局。

## 3. 境界与成长（设定·第三章）

### 3.1 境界（100 级）

凡人境 1-10 / 炼气 11-20 / 筑基 21-40 / 金丹 41-60 / 元婴 61-80 / 化神 81-95 / 渡劫大乘 96-100，各级修为需求（50/150/350/650/1000/1800/3000）、寿元上限（100/150/250/500/1000/3000/无量）、解锁能力照设定表实现。

### 3.2 战力

`战力 = 修为等级 + 主装备等级 + 主修功法等级`；外显/真实战力双轨 + 扮猪吃虎蓄力槽（外显显著低于真实时每月蓄力，释放时敌方斗法判定 -10%~-30%，上限=真实战力×2）。

**UI**：个人页战力环形图 + 评级徽章（凡尘→飞升 7 档）；外显战力独立小字显示；蓄力槽为进度条动效。

### 3.3 斗法判定（设定·第三章三）

- 战斗四性质：切磋较技 / 生死仇杀 / 妖兽战斗 / 自卫反击，各有收益惩罚表。
- 同修为（差≤5 级生死仇杀）：战力高者直接胜；相同则策略博弈（道韵+经验+环境）。
- 越级（差>5 级）：`基础胜率 = 20% + (玩家战力-敌方战力)×1%`，叠加命运骰子 7 档（⚡天赐良机 8% +25% … 💀天意弄人 8% -25%），钳制在 5%-95%。道韵/气运/连续越级修正骰子概率。
- **隐性反馈**：不显示胜率数值，用 7 档氛围文案提示（引擎选定档位→LLM 润色呈现）。

**演出**：战斗为强演出节点——骰子滚动动画（7 档表情符号轮盘减速定格）、胜率氛围文案打字机、结果揭晓闪光/震屏。

### 3.4 失败惩罚（设定·第三章四）

六行惩罚表（力竭被擒/重伤落败/被碾压击杀/元婴被灭/自爆逃脱）按战力差距触发；天命战斗保护（惩罚减半、死亡庇护、专属功法不可遗忘、⚠️风险标签）；惩罚减免因素（磐石之志、五行亲和、替死法宝、背景靠山）；恢复规则（突破奖励保留、装备可夺回、功法遗忘需重修）。NPC 落败对称惩罚。

### 3.5 三维道基（悟性/道心/根骨/气运/血脉）

五维各 1-100 级，经验曲线六段（启蒙 80/精进 200/大成 400/宗师 700/圣者 1200/道祖 2000 每级）。获取方式按设定表。

### 3.6 瓶颈与渡劫（设定·第三章六）

六大突破点（10→11、20→21、40→41、60→61、80→81、95→96），各含条件、天劫类型、成功奖励、失败惩罚。渡劫为强演出节点。

### 3.7 道韵-道基联动阈值

道韵等级 > 对应道基×2 触发瓶颈期（道韵经验减半），需跨维修行破局后获【一朝顿悟】。

## 4. 天命主线（设定·第六章，详见 06 号文档）

- 天命叩门 1-3 月固定选项；错过静待来年；阶段锁定修为达标触发；可永久无视。
- 【未竟仙途】显示：待抉择 / 已等待 X 年 / 进行中 / 已完成。
- 奖励体系：专属功法进阶、天命神通、专属体质血脉、本命法宝胚、法则碎片、领域雏形、道统信物、天命封号。
- 10 条主线 × 6 阶段全部实现为预写结构化 JSON 剧本（配置格式见 06 号文档）。
- 终章：五维回顾（仙途概览/关键抉择回溯/奖励总结/道缘宿敌概览/结局叙事）+ 封号自定义（2-8 字，系统给 2-3 推荐，不可更改）。

---

## 5. 非主线事件：因缘际会（设定·第七章）

每年 5 月末结算生成 6-7 月事件清单，六类：宗门大比/魔道会盟、秘境遗迹出世、兽潮天灾、跨域冲突、人物轶闻发酵、年度拍卖会。每类玩家方向 2-3 选（参赛/观战/无视等）。部分事件跨年延续。

实现为事件链状态机（见 04/06 号文档），首版重点实现**随机机缘**：坠魔谷、古修士洞府、上古遗迹等探索型秘境（多步状态机+判定+LLM 叙事）。

## 6. 地图系统：三层灵图（设定·第八章）

首版 **7 域浅层铺开**：三层架构完整、7 域天玄灵图全开、州府灵图每域生成核心区域、街坊灵图只做核心坊市与功能地点。

- **天玄灵图**（域级）：7 域节点 + 连线类型（白/黄/红/虚线传送阵）。
- **州府灵图**（区域级）：灵脉分布、势力版图、可探索地点、矿脉、物价指数；区域五项种子属性（灵脉浓度/妖兽密度/正魔比/秘境活跃度/遗迹密度）。
- **街坊灵图**（场景级）：地点名称、功能类型、准入条件、活跃传闻、常驻 NPC；坊市含店名/掌柜/层级/当季货品。

互动：自由描述想去之处；"逛坊市/感应灵脉"可生成 1-3 个新地点或传闻；准入条件校验（修为/身份/法宝/令牌/引荐）。

**UI**：三层钻入式地图页；竖屏下滑动切换层级，SVG 节点图 + 点击节点展开详情卡。

## 7. 仙资与灵物（设定·第九章）

- **货币**：下品灵石 / 中品(1:100) / 上品 / 极品 / 灵晶，统一钱包组件显示。
- **法宝 0-10 级**：凡器→先天至宝，等级/价格/威能表入库。
- **洞府 0-8 级**：凡人客栈→小世界，租金与修炼速度加成（+0%→+80%）。
- **功法五品**：凡/灵/地/天/仙（等级上限 30/50/70/90/100，每级战力 +0.8~2.0）；可切换主修，新功法从 Lv.1，旧功法保留。
- **背包/储物袋**：物品网格 + 分类页签（丹药/法器/功法玉简/灵材/符箓/任务物），数量与耐久显示。

获取途径：坊市购买、秘境探索、击杀掉落、任务奖励、百艺炼制。

## 8. NPC 与道缘系统（设定·第十一、十三章）

### 8.1 NPC 生成：池化复用模式（用户决策）

- **内置 NPC 池**：按域×势力×行当×境界预生成模板化 NPC 入池。
- **相似度匹配复用**：剧情需要一个"东荒筑基散修"时，先按标签相似度从池中拉取在世且未被占用过深的 NPC；无合适者才 LLM 生成新 NPC 入池。
- **规模受控**：每存档活跃 NPC 上限（建议 200）+ 全局池上限；超出后低相关 NPC 退化为抽象统计层。

NPC 属性：基础信息/修为境界/战力构成/性格道韵 2-3 项/身份归属/四维态度矩阵（亲疏敌友×敬重轻慢）/动态称谓/自身仙途目标/自主行动力。NPC 独立推进仙途（突破、陨落、结仇、获机缘），每月由演化引擎结算。

### 8.2 道缘层级

Lv.0 陌路→Lv.4 心腹/道侣，触发条件（往来次数/亲密度/共历事件）与解锁互动照设定表；亲密度增减与季度衰减、降级规则照设定。

**道友之能**：7 类每月被动技能（灵材援济/炼器支援/产业打理/风声通达/手作敬献/引荐延誉/仗义护持），心腹提升五成至一倍。

### 8.3 敌对系统（第十三章）

底层阻力/中层威胁/上层敌手/宿命大敌四层；每月扫描玩家行迹触发敌对动态；NPC 独立记录玩家公开行迹并调整评价。

### 8.4 道统人际（用户决策：首版纳入）

道侣（亲密度+共历事件达成，双修互动）、收徒（筑基期后）、生育/培育后代——服务传承系统（§11）。

## 9. 势力生态（设定·第十二、十四章）

- 五层金字塔 T0-T4，接触门槛照表。
- 势力属性模板：镇派功法/门内结构/势力范围/底蕴/对外态度/氛围/道统理念；关系四态（盟好/敌对/依附/井水不犯河水），每月势力骰子可触发反目和解。
- 玩家四重身份递进：过客→常客→外围→核心（门槛照表）。
- 天下演化（第十四章）：五项种子属性随机生成；每月六维演化判定（市价波动/天象异变/修士流动/势力消长/道缘网络/天降机缘）；事件三层结构（表闻/中变/底流）。

## 10. 天机简报（设定·第十五章）

每月初由演化骰子产出结构化动态列表，LLM 润色为四栏简报（修真域动态/势力消长/人物轶闻/灵材行情）。玩家可无视/择一回应/间接利用。

## 11. 修仙百艺、坊市、传承轮回

### 11.1 修仙百艺（第十章，首版纳入）

任意技艺或自创营生（LLM 生成成长维度与收益模型兜底）；1-100 级每 20 级晋升突破；收入=等级×系数+当月产出+市场需求；1 主修+2 辅修（50% 经验收入、上限折半）；6 个月未选技艺系统季末询问。首版内置：炼丹/炼器/制符/阵法/灵植/驯兽，自创营生走意图解析。

### 11.2 坊市三级交易（第十六章，首版纳入）

正市（公开、价稳、小议价）/ 地下黑市（需引入、大议价、以物易物）/ 宗门秘库·拍卖会（门槛制、重道缘贡献）。每月生成 3-6 件货架，支持自由描述购买/砍价/易物/闲聊（意图解析层处理）。

### 11.3 道统传承与轮回（第十七、十八章，首版纳入）

- **传承**：寿元将尽或主动触发，传承灵石资产/道缘网络/功法心得（道基部分继承）/本命法宝/心腹道缘，以继承者身份继续。
- **轮回**：完全重开（世界重置重随机）或轮回转世（世界延续，继承 50% 灵石、道基 30%、主修道韵 20%、核心功法、1-2 位心腹道缘、宿敌记忆）。
- 无硬性失败：身死道消→夺舍/轮回/转世分支。

## 13. 首版范围汇总

**包含**：角色创建全流程、核心回合循环、战斗判定全规则、境界/道基/道韵/功法、10 条天命主线全量、因缘际会事件链+随机机缘（秘境/洞府/遗迹）、三层灵图 7 域浅层铺开、坊市三级+背包、修仙百艺（6 内置+自创）、NPC 池+道缘+敌对+道侣/收徒、势力生态+天下演化+天机简报、传承与轮回、终章回顾、存档/道果码、新手引导（创建引导+首季度教学）、管理后台+运营分析。

**二期**：Web Push 推送、账号体系、PWA 离线、付费点落地、立绘资源、街坊灵图全量内容、州府灵图全量内容。
