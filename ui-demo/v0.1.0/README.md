# UI Demo v0.1.0

> 纯静态 HTML 演示稿（零依赖、双击即开），对应下一版游戏与后台的实现蓝图。
> 两份 demo 的交互均为演示数据，用于评审布局/信息架构/演出效果。

## 📱 game-landscape.html — 游戏横屏版

针对**手机横屏**（基准 667×375，兼容平板/桌面）的全新布局，替代竖屏单列方案：

```
┌──────────────── 顶栏：天玄历/骨龄/寿元(低寿红呼吸)/主线徽标 ────────────────┐
│ 左·角色面板      │      中·舞台（核心操作区）        │ 右·情报栏          │
│ ─ 立绘印章/姓名  │  场景氛围条（水墨渐变+光点动效）  │ ─ 未竟仙途         │
│ ─ 境界进度环     │  页签：决策罗盘/仙途叙事/斗法     │   （主线阶段条）   │
│ ─ 道基五维条     │  罗盘列表（类型色标/保鲜角标/     │ ─ 天机简报（四栏） │
│ ─ 战力/蓄力槽    │    天命金框/⚠️风险）             │ ─ 道缘速览 top3    │
│ ─ 灵石钱包       │  叙事流（打字机+光标）           │                   │
│ ─ 百艺+功能导航  │  底部：自由输入 + 进入下月 CTA    │                   │
└──────────────────────────────────────────────────────────────────────────┘
```

横屏设计要点：
- **左角色/中舞台/右情报**三区一屏尽收，无需滚动切换（竖屏版全部信息需上下翻）
- 决策罗盘 15 项一屏 7 项可见，金色天命选项置顶
- 演出层：命运骰子轮盘弹窗（旋转模糊→定格+七档文案）、月末结算浮层（飘字清单）、竖屏时显示"请旋转横屏"遮罩
- demo 交互：点击罗盘选项→结算浮层→查看叙事（打字机）；斗法页签→演示掷骰；自由输入→意图 toast

## 🖥️ admin-responsive.html — 管理后台多端版

**桌面=左侧导航，移动(<860px)=底部五 Tab+抽屉**；表格自动转卡片。九大模块：

| 模块 | 深化设计 |
|---|---|
| 📊 运营看板 | 5 KPI（DAU/新增/回合深度/LLM日成本/降级率告警）、留存漏斗（建角→1年→3年→终章，标注渡劫流失点）、DAU×成本双折线、境界分布、经济净流入通胀预警、世界健康度（NPC池命中率/链完成率/简报回应率） |
| 👥 玩家与存档 | 道果码/设备/角色名检索、状态筛选、只读快照/回放入口（传承二代标注） |
| 🧾 数值管理 | ref 表页签、行内编辑、**草稿→影响预览→发布**流（离线重放校验、版本快照隔离进行中存档） |
| 📜 主线剧本 | 10 主线网格（游玩人数+六阶段进度条）→ 节点图编辑（entry/choice/judgment/reward/expiry）+ 平衡校验报告 |
| 🤖 LLM 工厂 | 供应商卡（默认/场景路由/停用）、场景路由表、Prompt 版本 v7/v8 AB 灰度滑条、日成本 |
| 🔔 推送中心 | 广播编辑器+分群（活跃/卡渡劫点）、自动提醒策略（天命月/保鲜期/寿元） |
| 🎧 客服支持 | 道果码定位→四格快照→回合回放对比（引擎一致性校验）、"不可改档"红线 |
| 🛡️ 审计日志 | 时间线：发布/路由变更/广播/登录全留痕 |
| ⚙️ 系统设置 | 基础设施状态（PG/PITR/VAPID/部署）、密码轮换、限流与防 SL 策略 |

## 与现网实现的对应

- 游戏：现网为竖屏优先（`apps/web/src/app/game/page.tsx`），本 demo 为横屏改版蓝图——落地时替换页面布局与 CSS 变量（两版主题色一致）
- 后台：现网已有看板+推送+数值 CRUD（`/admin`），本 demo 补齐玩家检索/剧本管理/LLM 工厂/客服/审计五模块的交互稿
