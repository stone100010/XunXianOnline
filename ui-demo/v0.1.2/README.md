# UI Demo v0.1.2 — 管理后台 ECharts 指标增强版

> 吸收评审：图表全面改用 **ECharts 5**（本地 `lib/echarts.min.js`，离线可用），
> 并新增"让指标能驱动行动"的管理型模块：告警中心、玩家分层、数值平衡、经济分解。

## 评估结论（对 v0.1.1 的诚实回答）

v0.1.1 已有：漏斗+渡劫流失标注、降级率/成本、世界健康度——**有基础管理价值但不够**：
只有横截面漏斗（无 cohort）、指标不会主动找人（无告警）、无玩家分层（无法差异化运营）、
经济只有一条净流入线（无法定位是哪个来源失控）、引擎实际分布 vs 理论公式缺失（数值监控不闭环）。

## v0.1.2 新增的"更具管理效果"指标

| 模块 | 图表（ECharts） | 管理决策价值 |
|---|---|---|
| 📊 看板 | DAU×成本双轴折线（范围切换联动）、**周 Cohort 留存热力图**、**流失节点直方（渡劫月红标+均值线）**、境界柱状、**罗盘选项占比环** | 回答"谁在何时流失、玩家到底在玩什么" |
| ⚠️ 告警中心（新） | 阈值表：当前值/阈值/持续/建议动作/直达链接 | 指标主动找人；每条告警配"建任务/调数值"动作，而非只看 |
| 👥 玩家分层（新） | **气泡散点（活跃×仙途年数，沉睡线/核心线/核心区标注）**+五层策略表 | 新手引导/成长陪伴/核心深耕/沉睡唤醒/流失召回，差异化运营 |
| ⚖️ 数值平衡（新） | **渡劫成功率 实际vs理论（偏差标注）**、**越级战斗胜率 实际vs理论曲线（发现蓄力槽偏强）**、惩罚档位堆叠、**命运骰子公平性（设计vs实际频率）** | 规则引擎运行时监控闭环：理论→实际→告警→调参→复测 |
| 💰 经济监控 | **产出/消耗来源分解堆叠面积**、**灵石流向 Sankey**、调控工具按钮（联动数值草稿） | 通胀可定位到来源（秘境产出失控 vs 消耗不足） |
| 📜 主线剧本 | **10 主线×6 阶段到达率横向堆叠**、热度表、**LLM 归因放弃原因** | 找到"哪条主线的哪一阶在赶人"，并给出调门槛/调判定的动作 |
| 🤖 LLM 成本 | **降级率仪表盘（gauge）**、场景成本环、**Prompt A/B 五维对比** | 成本与质量归因到场景与版本 |
| 🌍 世界健康 | 三指标趋势线、**七域雷达** | 开放世界运转的独有视角 |

## 使用

- 双击打开 `admin-responsive.html`（`lib/echarts.min.js` 本地加载，无需网络）
- 在线：`:1234/ui-demo/v0.1.2/admin-responsive.html`
- 交互：时间范围切换联动 KPI+折线；告警卡点击直达对应模块；图表悬浮 tooltip 全量
