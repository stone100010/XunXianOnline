# UI Demo v0.2.1

> v0.2.0 修复版：**页面不再锁死，全面支持上下滑动**（桌面滚轮 + 移动端触摸惯性滚动）。

## 滚动性修复清单

| 问题（v0.2.0） | 修复（v0.2.1） |
|---|---|
| `.page` 用 `position:fixed; inset:0` 锁死视口，内容超出即被裁切 | 改为**文档流布局**：子页面 display 切换，内容自然撑高，`html/body` 正常滚动 |
| `html,body{overflow:hidden}` 全局禁滚 | 仅主页（三区布局）保留 `100dvh + overflow:hidden`（分栏各自内滚），子页全部交给页面滚动 |
| 移动端触摸滚动无惯性 | 全局 `-webkit-overflow-scrolling:touch` + 滚动容器 `touch-action:pan-y` |
| 子页头部随滚动消失 | `.phead` 改 `position:sticky` 置顶 |
| 长页面无处回顶 | 新增右下角 **↑ 回顶浮动按钮**（滚动超 120px 显现，平滑回顶） |
| 竖屏遮罩强制阻断 | 改为建议提示，提供「竖屏继续」按钮可跳过 |
| 页面切换 | 保留入场动画（淡入+右滑），切换自动回顶 |

## 六大功能页（同 v0.2.0 设定设计）

坊市（三级网络）/ 背包（六分类）/ 道缘（态度矩阵+道友之能）/ 灵图（三层钻入）/ 灵兽（契约忠诚）/ 传承（衣钵预览+传法仪式）——全部整页跳转、长内容自由滑动。
