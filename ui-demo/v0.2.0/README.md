# UI Demo v0.2.0

> v0.1.1 迭代：游戏**左下角百艺面板六个子功能全部改为整页跳转**，每个子页严格按设定文档独立设计，不再是侧板。

## 📱 game-landscape.html — 多页版游戏 UI

主页保持三区布局（左角色/中舞台/右情报），左下角功能导航点击后**滑入全新整页**（带返回头 + 上下文徽标）：

| 页面 | 依据设定 | 页面设计 |
|---|---|---|
| 🏺 **坊市** | 十六章·三级交易网络 | 正市/地下黑市/宗门秘库三页签：正市 6 件价稳小议价；黑市暗红边框+禁术/赃物/令牌/情报，议价 30% 且会失败（"掌柜摇头"）；秘库金丹准入锁定展示贡献度兑换（功法/化婴丹/上古遗宝） |
| 🎒 **背包** | 九章·储物袋 | 全部/丹药/法器/灵材/符箓/任务物六分类页签，12 件物品网格（数量角标/耐久-1 标注），本命法宝金框高亮 |
| 👥 **道缘** | 十一章·完整属性 | 每位 NPC 卡：行当+境界、五级层级 pill、好感条（宿敌红色负值）、**四维态度矩阵（亲疏/敌友/敬轻/往来）**、**道友之能**技能行（灵材援济/手作敬献等），底部独立"宿敌"分组 |
| 🗺️ **灵图** | 八章·三层钻入 | 天玄灵图（SVG 七域节点+四色连线：白商路/金妖兽/红险地/虚线传送阵，点击钻入）→ 州府灵图（区域卡：五项种子属性双仪表条+活跃传闻）→ 街坊灵图（地点准入 pill+常驻 NPC+当季货品），面包屑逐层返回 |
| 🐉 **灵兽** | 御兽/驯兽 | 契约兽卡（等阶/技能/忠诚条），协同作战/喂食交互，第三契约位锁定（驯兽术 Lv.20 解锁提示） |
| 🏛️ **传承** | 十七章·道统传承 | 可传资产四卡预览（灵石 90%/储物袋整袋/心腹道缘/功法心得六成）+ 继承者命名 + 开坛传法确认仪式弹层 |

主页交互保留：15 项决策罗盘、月末结算→打字机叙事、命运骰子轮盘、自由输入意图、竖屏旋转遮罩。
