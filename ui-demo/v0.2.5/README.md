# UI Demo v0.2.5 — 管理后台「玩法设定」增强版

> 基于 v0.1.2（暗色 + ECharts）扩展：新增**玩法设定**五模块，覆盖游戏内容侧的运营配置。
> 侧栏分组：运营（看板/告警/分层）· 数值（平衡/经济）· **玩法设定（机缘/坊市/NPC 池/灵兽/世界演化）** · 内容（主线/LLM/世界健康）

## 新增五模块设计

### 🎲 机缘活动管理
- **活动日历**（custom series 月历格：金=秘境开启 红=兽潮 蓝=拍卖会）
- 秘境触发漏斗：罗盘出现 100% → 进入 64% → 通关 38% → 核心奖励 11%
- 奖励池玫瑰图（坠魔谷：魔晶 34%/灵石 26%/功法残卷 14%/法器/丹药/空手 5%）
- 参数配置表：入口门槛/出现率/判定成功率/核心奖励，行内编辑 + 存草稿 + 发布（新月生效）；新秘境「九幽龙渊」走灰度

### 🏪 坊市管理
- 三级市场货架规则表：准入/件数/价格波动/议价空间/抽成（正市±20%议价5% · 黑市±35%议价30%抽5% · 秘库贡献点制）
- 坊市收入构成（按市场堆叠柱）
- 四类物品物价指数 30 日曲线（妖兽内丹 +42% 通胀警示）
- 议价与滞销运营：滞销品一键下架、热销品提价

### 👤 NPC 池管理
- 池命中率趋势（复用 83% vs 新生成 17%，健康线 75%）
- 职业分布环形图（在世 1,842 位 × 10 职业）
- **LLM 生成审核队列**：相似度评分（>0.7 标 ⚠️），通过入池/驳回计模板
- 生命周期表：池容量 92%、在世/陨落/夺舍、模板合并、宿敌激活数

### 🐉 灵兽管理
- 持有分布气泡图（持有率 × 战力贡献，火羽鹰 32% 持有偏高红标）
- 培育链路漏斗：兽蛋 640 → 孵化 65% → 成年 70% → 进化 21%
- 种类参数表：品阶/孵化率/饲料月耗/战力贡献/持有率，平衡调参 + 新兽灰度

### 🗺️ 世界演化
- 七域种子参数滑条（灵脉/妖兽/秘境/遗迹 ×7 域，新月生效）
- 演化事件三层分布（表闻堆叠柱 + 中变 + 底流折线）
- **势力关系图**（graph 可拖拽缩放：红=敌对 金=盟好，箭头=依附方向）
